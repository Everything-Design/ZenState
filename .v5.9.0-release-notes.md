# ZenState 5.9.0 — Capture now, sync when ready

- Start Quick Record Time from the menu, Plan, or the running timer pill without choosing a Basecamp task first.
- Review every unposted session in Timesheet. Map one session or select several to sync as separate entries on one Basecamp to-do. Each keeps its original date, duration, and note.
- Search pinned to-dos in the menu, including tasks inside collapsed folders.
- Optionally keep Today and Tomorrow plans separate. Due Tomorrow items wait for an explicit move or reschedule, while unfinished Today items carry forward.
- Edit a session's local start time in Timesheet and preserve short session durations when updating Basecamp.
- Remove the unused Team time tab.

Sessions remain available for retry when Basecamp is disconnected or rejects a post. If a connection drops during a post, check Basecamp before retrying in case it accepted the entry without returning a response.

Available for Apple Silicon and Intel Macs, Windows x64, and Linux x64 (AppImage and Debian).
