# ZenState 5.9.3 — Keep automatic updates working

- Moves future automatic updates to the public `Everything-Design/ZenState-Releases` repository so the source repository can become private after the team migrates.
- Install this version before the source repository becomes private. Older versions will need a manual update if they miss the transition.
- Time recording, saved records, settings and Basecamp/Ops sign-in behavior are unchanged.

Available for Apple Silicon and Intel Macs, Windows x64, and Linux x64 (AppImage and Debian).
