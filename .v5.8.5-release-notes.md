# ZenState v5.8.5 — Choose when your work started

When logging a task after you finish it, choose the date and actual start time so it appears at the right time in your ZenState timesheet.

- Available in both **Plan → Log time** and **Timesheet → Add session**.
- Compact inline hour and minute fields with AM/PM, prefilled with the current local time.
- A calendar that matches ZenState's interface, with Today and Yesterday shortcuts.
- Keyboard support for editing time, plus validation for invalid dates and times.

Start time is saved only in ZenState. Linked Basecamp entries continue to receive the selected date, duration and description.

Includes Windows x64, Apple Silicon and Intel Mac, and Linux x64 (AppImage and Debian) installers and update files. Finish and save any running timer before updating.

As with v5.8.4, Windows builds are unsigned and Mac builds use the existing Apple Development identity without notarization.
