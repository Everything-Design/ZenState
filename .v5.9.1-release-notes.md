# ZenState 5.9.1 — Sync time from the dashboard

- The dashboard's **Sync Basecamp** button now runs the same history sync as Settings. It posts each mapped, unsynced session as its own Basecamp time entry and stays on the current tab when all time is synced.
- If any sessions still need a Basecamp destination or a retry, ZenState opens Timesheet and shows what remains. Failed posts stay available for review.
- Settings now explains that history sync handles mapped sessions and that unlinked time is mapped in Timesheet.

Available for Apple Silicon and Intel Macs, Windows x64, and Linux x64 (AppImage and Debian).
